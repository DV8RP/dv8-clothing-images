# dv8-clothing-images

Clothing preview thumbnails for kartik-clothing on the DV8 RP FiveM server, generated in-game with `/takeshots`.

kartik-clothing loads them from `Config.MediaUrl`:

    https://raw.githubusercontent.com/DV8RP/dv8-clothing-images/main/preview

Layout: `preview/<male|female>/<slot>/<drawable>.webp`, with texture variations as `<drawable>_<texture>.webp`.
Do not edit by hand. Re-sync from the server with `sync.ps1` after each `/takeshots` run.
